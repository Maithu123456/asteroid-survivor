Asteroid Survivor is a lightweight, retro-style 2D space shooter built using pure HTML, CSS, and JavaScript. Control your ship with either the arrow keys or your mouse, destroy incoming asteroids, and collect glowing stars to build up your high score. It features built-in sound effects, particle explosions, and local high-score saving—all packed into a single, self-contained index.html file. Just double-click the HTML file to open it in any web browser and play instantly.
